Suppression de Compte - Zoma

Comment supprimer votre compte

Vous pouvez supprimer votre compte Zoma directement depuis l'application mobile.

Étape 1 : Ouvrez l'application Zoma sur votre téléphone
Étape 2 : Connectez-vous à votre compte
Étape 3 : Allez dans Profil (icône en bas à droite)
Étape 4 : Cliquez sur "Paramètres du compte"
Étape 5 : Cliquez sur "Supprimer mon compte"
Étape 6 : Suivez les instructions à l'écran :
  • Locataires : Vous devrez confirmer votre intention (3 étapes), puis entrer votre mot de passe
  • Propriétaires : Vous devrez entrer votre mot de passe pour confirmer la suppression

Processus de suppression

Suppression différée (30 jours) - Locataires

Si vous êtes locataire, votre compte sera mis en suppression différée. Vous avez 30 jours pour le restaurer si vous changez d'avis.

Pour restaurer votre compte, connectez-vous simplement avec vos identifiants pendant cette période de 30 jours.

Suppression immédiate - Propriétaires

Si vous êtes propriétaire, la suppression de votre compte est immédiate et définitive. Toutes vos données seront supprimées de manière irréversible dès la confirmation.

⚠️ Attention : Cette action ne peut pas être annulée. Assurez-vous de vouloir vraiment supprimer votre compte.

Après 30 jours (pour les locataires)

Si vous êtes locataire et que vous ne restaurez pas votre compte dans les 30 jours, la suppression devient définitive et toutes vos données seront supprimées de manière irréversible.

Données supprimées

Lors de la suppression de votre compte, les données suivantes seront supprimées :

  • Vos informations de profil (nom, prénom, email, téléphone)
  • Vos réservations
  • Vos propriétés (si vous êtes propriétaire)
  • Vos messages
  • Vos avis et commentaires
  • Vos tickets de support
  • Toutes les autres données associées à votre compte

Données conservées

Certaines données peuvent être conservées pour des raisons légales ou de sécurité :

  • Données d'audit (pour une durée maximale de 2 ans)
  • Données financières liées aux transactions (conformément aux obligations légales)

Besoin d'aide ?

Si vous rencontrez des difficultés pour supprimer votre compte ou si vous avez des questions, vous pouvez :

  • Contacter notre support via l'application (Profil → Support)
  • Envoyer un email à : support@zoma.app
