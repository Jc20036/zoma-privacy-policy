## 🔗 URLs publiques

Une fois GitHub Pages activé, les pages seront accessibles à :

- **Politique de Confidentialité :** `https://Jc20036.github.io/zoma-privacy-policy/privacy-policy.html`

## 📝 Mise à jour

Pour mettre à jour une page :

1. Modifier le fichier HTML correspondant (`privacy-policy.html` ou `delete-account.html`)
2. Mettre à jour la date de "Dernière mise à jour" dans le fichier
3. Commit et push vers GitHub
4. Les changements seront visibles après quelques minutes

## 🚀 Utilisation dans Google Play Console

Ces URLs sont utilisées dans le formulaire Google Play Console :

- **Politique de Confidentialité :** URL de la politique de confidentialité
- **Suppression de Compte :** URL de suppression de compte

## ✅ Vérification

Avant d'utiliser les URLs dans Google Play :

1. ✅ Ouvrir les URLs dans un navigateur (navigation privée)
2. ✅ Vérifier que les pages s'affichent correctement
3. ✅ Vérifier que les URLs commencent par `https://` (pas `http://`)
4. ✅ Vérifier que les pages sont accessibles sans authentification
