# Politique de Confidentialité - Zoma

Ce dépôt contient la politique de confidentialité de l'application Zoma, hébergée sur GitHub Pages.

## URL publique

Une fois GitHub Pages activé, la politique sera accessible à :
```
https://Jc20036.github.io/zoma-privacy-policy/privacy-policy.html
```

## Mise à jour

Pour mettre à jour la politique de confidentialité :
1. Modifier le fichier `privacy-policy.html`
2. Mettre à jour la date de "Dernière mise à jour"
3. Commit et push vers GitHub
